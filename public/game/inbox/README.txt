INBOX — PNG crudos de ChatGPT
==============================

1. Descargá cada imagen de ChatGPT
2. Renombrá con el nombre EXACTO del brief (ej. dino-run-1.png)
3. Pegá acá (esta carpeta)
4. En la terminal del proyecto: npm run game:prepare

El script quita fondo blanco, encaja en 512×512 y copia a public/game/
